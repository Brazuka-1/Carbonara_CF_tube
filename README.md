# Carbonara Lightweight CF Tube

Carbonara is a high-endurance, high-quality carbon fiber X-beam for Voron and Monolith 3D printers, designed for stock build sizes of 250, 300, and 350.

![Carbonara Stickers](https://i.imgur.com/Q5H2WDR.png)

---

## Key Features

- High torsion resistance  
- High-temperature resin (110 °C short-term resistance, suitable for 90 °C chamber use)  
- Ultra-light: up to 58% weight reduction vs 2020 aluminium extrusion (before hardware and inserts)  
- Smooth 3K carbon fiber finish  
- Pre-drilled for easy installation  
- Excellent price-to-performance ratio  
- Real-world prototype testing results:
  - [Test log 1 - Compression and temperature](https://monolith-gantry-updates.zen3d.eu/carbon-fiber-x-beam-prototype-testing/)  
  - [Test log 2 - Torsion and temperature](https://monolith-gantry-updates.zen3d.eu/carbonara-x-beam-prototype-testing-2/)

Tested for 800 hours at high speeds:
500–1300 mm/s @ 50,000–100,000 m/s² with an 80 °C chamber.

## IMPORTANT

- Printed inserts are **mandatory** for performance  
- All inserts must be aligned and facing the same direction  
- Inserts must be a snug fit (not loose)  
- Hollow spacers are optional and only for installation ease  
- Use CF/GF filament with HDT ≥ 110 °C (e.g. annealed PET-CF, PC-PBT GF, etc.)  
- The indented part of inserts must face the linear rail (see image or CAD)
